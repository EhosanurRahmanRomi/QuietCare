QuietCare feature coverage

Version 0.3.0 preview · 23 October 2026. This map distinguishes features implemented in QuietCare from tools opened in Windows and capabilities that are not implemented.

AreaAvailabilityWhat the build actually does
Care scanSix live read-only checksActual temp/startup/memory/disk/app/Defender observations, per-step states, current item, Skip/Stop, expandable results. No auto-fix or malware engine.
QuietCare updatesImplementedManual checks, opt-in weekly startup check, channels, verified installer and support links. No silent installation. See UPDATES.md.
Performance monitorImplementedTiny transparent auto-width CPU → GPU → RAM strip, measured 205 × 28 pixels in the native preview. Main UI has transparent integrated controls and no separate title strip. Drag, expand, hide, topmost, transparency, 100–10,000 ms polling. Expanded disk and network readings collected on demand. Sampling pauses when fully hidden; main UI is built lazily.
RAM Boost / Smart RAMImplemented, direct + optional manualClick the floating lightning button to trim qualifying idle background working sets without a chooser. Protects foreground processes, normal-priority active browser renderers, media and common project tools; extra exclusions in Settings. No killing, suspending or tab discard. Optional manual selection remains. No guaranteed speed improvement.
Auto RAM clean / CPU saverNot implementedQuietCare does not automatically purge memory, kill apps, or disable services.
Startup optimizerImplemented + WindowsDirect disable/restore for current-user Run entries with backups. Lists machine-wide and folder entries. Other startup types use Windows Startup settings, Services and Task Scheduler.
Junk file cleanImplemented, conservativePreview selected old user-temp files, quarantine with recovery, restore, and confirmed permanent deletion. System caches and update leftovers open Windows cleanup.
Scheduled cleanupWindows integrationConfigure Windows Storage Sense. QuietCare does not install a scheduled background service.
Large-file finderImplementedFolder chosen by the user; show up to 500 largest files at least 100 MB. Read-only results and Explorer inspection.
Duplicate-file finderImplementedSize grouping and SHA-256 content matching with a bounded hashing budget. Review-only; no automatic duplicate deletion.
System informationImplemented + WindowsLocal CPU/GPU/Windows/drive inventory, physical memory, and a full Windows System Information entry point.
Temperature / fan sensorsNot implementedNo kernel hardware driver is included. CPU/GPU usage remains available through Windows counters.
Turbo / power optimizationPower plans + WindowsBalanced, performance and battery-saver power plans where supported; original-plan recovery. Windows Game Mode, visual effects and graphics preferences.
Disk optimizationWindows integrationWindows Optimize Drives chooses supported SSD/HDD operations. Disk Management and Storage settings are available.
Privacy sweep / anti-trackingPrivacy settings onlyOpen Windows privacy, diagnostics, activity and browser defaults. No browser history, cookies, password or fingerprint cleanup engine.
Antivirus / spyware removalWindows integrationOpen Windows Security. QuietCare is not an antivirus engine and does not claim to scan for malware.
Firewall / security reinforceWindows integrationOpen Windows Firewall and System Protection. QuietCare does not disable security features or apply unexplained registry changes.
Software / driver healthInventory + WindowsDesktop app inventory, Windows Update, optional drivers, Microsoft Store updates, Device Manager and Windows uninstall. No independent vulnerability or driver database.
Internet boostNetwork toolsLive network activity, adapter/network/proxy/data-usage entry points. No claimed bandwidth increase or automatic TCP/DNS tweak.
Registry cleaner / defragNot implementedNo general registry deletion or registry defragmentation. Startup edits are narrow and backed up.
Repair / shortcut fixWindows repair entry pointsWindows troubleshooting, recovery and reliability history. No arbitrary shortcut deletion or automatic repair engine.
Rescue centerImplemented for own changesTemp quarantine recovery, startup backups and previous power plan. Does not back up unrelated apps' changes.
VPN / secure erasure / browser extensionsNot implementedNo bundled third-party services or extensions, subscription, VPN, or secure-erasure claim.

Build and test evidence is included in VALIDATION.md. Read USER-GUIDE.txt for cleanup boundaries and usage. No software is guaranteed bug-free or secure; this preview is unsigned and has not been independently security-audited.
