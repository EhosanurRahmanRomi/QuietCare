QuietCare's first public Windows preview brings a tiny transparent performance monitor and focused maintenance tools without ads, accounts, or telemetry uploads.

![QuietCare native interface](https://raw.githubusercontent.com/EhosanurRahmanRomi/QuietCare/v0.2.0/docs/images/QuietCare-preview.png)

### Downloads

- **QuietCare-Setup.exe** — per-user installer, Start menu shortcuts and uninstaller.
- **QuietCare.exe** — portable application.
- **QuietCare-source-v0.2.0.zip** — tagged source, tests, documentation and screenshots.
- **SHA256SUMS.txt** — integrity checksums for the release files.
- **VALIDATION-v0.2.0.txt** — local test evidence, binary hashes and scope limits.

Requires Windows 10/11 x64 and .NET Framework 4.8 or later. Normal installation and use do not request administrator access. The executables are unsigned; checksums do not replace a publisher signature.

### Highlights

- Content-sized transparent CPU → GPU → RAM monitor, captured at 205 × 28 px.
- Adjustable 100–10,000 ms refresh and transparency; expanded disk/network details.
- Direct floating Smart RAM Boost with active-app/browser/media/project exclusions, extra protected app names, capped work and a cooldown. No chooser, app termination or tab discard.
- Continuous navy main canvas, transparent window controls, compact navigation and focused action cards.
- Recoverable old-temp cleanup, current-user startup backup/restore, file discovery, local inventory and fixed Windows tool integrations.
- Lazy main UI, compact-only sensor work and paused hidden polling.

### Evidence

**42 core + 20 WPF UI + 4 isolated installer checks passed locally.** A live test trimmed only a dedicated memory helper and verified every byte of its 96 MB allocation. Native main/monitor layout and maximize/restore were reviewed on the reference PC.

Short floating-only observations on one i5-8350U / UHD 620 / 16 GB machine were 0.146% total CPU at 1,000 ms, 0.703% at 250 ms and 1.601% at 100 ms, with approximately 97–100 MB working set. Each measured about 20 seconds after warmup; these are local observations, not guaranteed bounds or battery/soak results.

### Preview limits

Working-set trimming does not free an app's allocated data and may cause later paging latency. It is not a speed guarantee. QuietCare protects the whole active browser family because it cannot inspect individual tab contents. Some tools open Windows settings/consoles; there is no antivirus, independent driver updater, hardware temperature driver or full Advanced SystemCare feature parity. Other products are not automatically uninstalled.

No independent security audit, broad hardware/scaling matrix, prolonged soak test or code signing has been completed.
