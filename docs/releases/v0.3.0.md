## Live checks, clear Boost results and app updates

QuietCare now shows what it is checking and what a Boost click actually did. This is an unsigned Windows x64 preview, with limited hardware coverage and no independent security audit.

- **Care scan:** six real read-only checks for temporary files, startup entries, memory, fixed-drive space, desktop apps and Defender status. Watch the current category/item, skip a step or stop, then expand observations and choose a review action. Partial and unavailable checks remain visible. Scan does not apply fixes or run a malware engine.
- **RAM Boost:** the floating button still runs directly. Results separate accepted requests from measured resident-memory decreases, show physical RAM before/after, and explain protected/skipped or declined processes. An OS-background browser-renderer setting adds carefully bounded eligibility inside an active browser; normal-priority active renderers, foreground processes, browser audio, controllers, extensions and common project tools remain protected. Add browser exclusions for background web projects.
- **Maintenance:** searchable startup entries and live temp-scan counts with a Stop button. Existing backup, quarantine and restore boundaries remain in place.
- **App updates:** Check for updates, preview/stable selection, plain-text notes, support links and an optional weekly startup check (off by default). Installer downloads use fixed project URLs, bounded HTTPS redirects, expected size and SHA-256, Internet marking and revalidation before user-confirmed opening. No silent installation.
- **Research/docs:** whole-app professional workflow comparison and source review of 11 related GitHub projects, with licenses, implementation references, feature gaps and a maintainer update-feed procedure.

### Validation and limits

Local checks cover core/process protection and dedicated-helper data preservation, real WPF controls, isolated installer lifecycle, updater safety fixtures, and a live read-only Care scan. The release includes sanitized detailed evidence and checksums; hosted CI is separate from physical-device validation.

Working-set trimming can be temporary and can cause later page faults. Accepted requests and lower resident memory do not guarantee faster apps or a lower overall RAM percentage. QuietCare never requests app termination, tab discard, global standby purges or security weakening. It cannot identify unsaved content inside browser tabs. The wider commercial-suite features that are not implemented are listed in the feature map.

### Download

Use `QuietCare-Setup.exe` for per-user installation or `QuietCare.exe` for portable use. Windows 10/11 x64 and .NET Framework 4.8+ are required. Review the unsigned preview and its provenance before running it. `SHA256SUMS.txt` verifies byte integrity, not publisher identity.
