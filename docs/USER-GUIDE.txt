QUIETCARE 0.3.0 - WINDOWS PREVIEW
23 October 2026

GET STARTED
QuietCare-Setup.exe installs for your Windows user with shortcuts/uninstaller.
QuietCare.exe is portable. Windows 10/11 x64 and .NET Framework 4.8+ are required.
The preview is unsigned; normal use requests no administrator access. No other
utility is automatically removed. Integrated transparent window controls share
the page background. Drag the sidebar branding or empty top edge to move;
double-click to maximize/restore. Close hides to tray by default. Choose Exit
in the notification icon or monitor menu to stop the app. Relaunch reveals it.

LIVE CARE SCAN
Choose categories beside SCAN. The six actual read-only checks cover temporary
files, startup entries, memory, fixed-drive space, desktop apps and Defender
status. Watch the category/item, elapsed time and completed-category count.
Skip affects one step; Stop retains finished results. Windows calls can take
time to respond to cancellation. Expand observations and choose a review action.
No fixes are applied. Partial/unavailable does not mean clean. Registrations
are not automatically startup problems. Inventory is not a vulnerability or
outdated-version scan; Defender status is not malware scanning. No health score
is invented.

FLOATING MONITOR
The tiny transparent strip shows CPU, GPU, RAM. Drag its readings to move;
double-click or use the arrow to expand disk/network details. Right-click for
refresh, Boost results, settings, hide and exit. Settings provides 100-10,000 ms
refresh, topmost mode and transparency. Source counters may update less often
than the requested cadence. Faster polling uses more CPU. Compact mode collects
CPU/GPU/RAM only, main UI is lazy, and disk/network is demand-only. Hidden or
suspended monitoring stops; a minimized main window without a widget also stops.
Short local benchmarks are not universal CPU/battery limits.

SMART RAM BOOST
Click the lightning button for direct Boost, without a chooser. Its 12-second
popup has an optional View Boost results link. Results distinguish accepted
requests from measured resident decreases, show per-process and physical-RAM
before/after values where accessible, and explain protected/skipped or declined
requests. Missing measurements are unavailable, never invented savings.

Boost uses EmptyWorkingSet. It never kills/suspends/restarts apps, discards or
reloads tabs, purges standby memory, fills RAM or changes browser settings.
Foreground processes, audio/calls, Windows and common project tools are protected.
Busy, young, small, inaccessible or identity-changed processes are skipped.
Unknown media state prevents changes. Work is capped to 12 accepted requests,
a five-second trim-loop budget and a 30-second cooldown. Native calls add time.

Settings > Include OS-background browser renderers allows idle/below-normal
priority renderers inside an active browser, with repeated/fresh checks. It is
on by default; switch it off to protect the entire active browser family.
Controllers, extensions and browser families playing audio remain protected.
Background priority is not knowledge of tab contents. Add chrome.exe (or your
browser name) to protected processes to protect all background web projects.
Pages can return immediately with latency. Committed allocations are not freed;
accepted requests/lower RAM do not guarantee faster apps. Other workload changes
the physical-RAM reading. Manual selected-app trimming remains optional with
confirmation. See RAM-BOOST.md for the exact policy and limits.

APP UPDATES
Use Updates > Check for updates or the notification icon's check action. Review
version/result/plain-text notes, download the verified installer, then choose
Open installer when ready. Preview/stable choice and the optional weekly startup
check are in Settings. Startup checks default off. No recurring timer, automatic
download or silent installation runs. Failed/canceled checks are not up to date;
attempts count toward the weekly interval. Manual checks have a one-minute
per-session cooldown. Size, exact project URL, SHA-256 and Internet marking are
validated; the hash is rechecked before user-confirmed installer opening. Normal
Setup still requires your choice. Windows warnings are not bypassed. GitHub
receives ordinary network metadata/app version, not inventory/files/credentials.
SHA-256 is byte integrity, not publisher identity. See UPDATES.md.

STARTUP AND TOOLBOX
Startup Optimizer searches by name, source or command. Current-user Run entries
can be backed up, disabled and restored without overwriting collisions. Machine
and folder entries are read-only. Services/tasks and other types use Windows
settings/consoles. Registered does not prove effective enabled state; no boot
impact is guessed. Enable QuietCare startup after choosing its final location.
The toolbox has 37 fixed Windows entry points. Security, privacy, storage,
updates/drivers, Store, services/tasks, backup and networking open named Windows
tools. Local tools include app/hardware inventory, bounded large/duplicate file
discovery, original power-plan recovery and latest-900-sample CSV export. Missing
counters stay empty. No independent malware engine, driver database, registry
cleaner, VPN, browser-history/password cleaner or temperature/fan sensor exists.

CLEANUP AND RECOVERY
Temp scanning shows examined entries/candidates/bytes and Stop. It checks only
current-user LocalAppData/Temp: TMP/TEMP/LOG/ETL/DMP/CACHE older than seven days,
at most 512 MB each, 30,000 entries or 20 seconds total. Limits yield partial
results. Linked/hard-linked/locked/inaccessible/changed files are excluded.
Documents, Downloads, browser profiles, cookies/passwords are outside the policy.
Selected files move to same-drive QuietCare Recovery. Quarantine does not
reclaim space: review, restore, or confirm permanent removal. Permanent deletion
cannot be undone. Changed recovery content/stale metadata is rejected; restore
never overwrites. Duplicate/large-file discovery does not delete files.

DATA, UNINSTALL AND EVIDENCE
Settings, local activity log, update cache and backups: %LOCALAPPDATA%/QuietCare.
Installed app files: %LOCALAPPDATA%/Programs/QuietCare. Local data is not encrypted
by QuietCare. Uninstall via Windows Installed apps or Start > QuietCare.
Restore startup/power choices you want first. Uninstall keeps settings/recovery/
backups and unrelated shortcut targets; a small Temp helper remains.
The dated test evidence in VALIDATION.md separates core, WPF controls, offline
updater, live read-only Care and isolated installer checks. Live Boost testing
uses only a dedicated helper and verifies its 96 MB data; user-app trimming is
not tested. No all-app/no-bug/security/performance guarantee is made. There is
no Authenticode signing or independent security audit. Source is MIT licensed.
BUILDING.md has commands; RELATED-PROJECTS.md and FEATURES.md map whole-app
professional features, delivered behavior and further implementation work.
