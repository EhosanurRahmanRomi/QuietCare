# Security policy

QuietCare is an unsigned preview and has not received an independent security audit. No version is represented as universally bug-free, secure or production-qualified.

## Supported version

Security fixes currently target the latest preview source on `main` and the v0.3.x preview line. Older local previews have no separate maintenance commitment.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/EhosanurRahmanRomi/QuietCare/security/advisories/new) for this repository. Include the affected version/commit, minimal reproduction with synthetic data, likely impact and any proposed mitigation. Do not attach credentials, real recovery data, private app command lines or unrelated personal logs.

Avoid public issues for exploitable details until the maintainer has had an opportunity to investigate. A response or remediation timeline is not guaranteed; this is a small independently maintained preview project.

For ordinary bugs without sensitive security details, use the [bug report form](https://github.com/EhosanurRahmanRomi/QuietCare/issues/new/choose). The [security model](docs/SECURITY-MODEL.md) documents intended boundaries and limitations.
